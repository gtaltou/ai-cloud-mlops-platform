# Contributing Guide

Thank you for contributing.

---

## Branch Strategy

### Main

Production-ready code only.

### Develop

Integration branch.

### Feature Branches

```text
feature/<feature-name>
```

Examples:

```text
feature/rag-ingestion
feature/bedrock-integration
feature/langfuse-observability
```

---

---

## Pull Requests

Requirements:

- Clean commits
- Updated documentation
- Passing CI
- Code review completed

---

## Coding Standards

### Python

- Ruff
- Black
- Type Hints

### TypeScript

- ESLint
- Prettier

## Architecture Decisions

Major architectural changes must be documented via ADRs.
