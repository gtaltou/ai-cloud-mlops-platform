# MCP Compromise Response Runbook

---

# Trigger

Suspected compromise of:

- GitHub MCP
- Filesystem MCP
- Database MCP
- Cloud MCP

---

# Containment

Immediately:

- Disable MCP Connection
- Rotate Credentials
- Remove Access Tokens

---

# Investigation

Review:

- Tool Executions
- Audit Logs
- Access Patterns

---

# Recovery

- Recreate Credentials
- Revalidate Permissions
- Re-enable Connection
