# Prompt Injection Response Runbook

---

# Detection

Indicators:

- Unexpected Tool Calls
- Sensitive Data Requests
- Instruction Override Attempts

---

# Immediate Actions

1. Stop Session
2. Preserve Logs
3. Record Prompt Payload
4. Review Tool Access

---

# Investigation

Review:

- User Prompt
- Agent Traces
- MCP Calls
- Retrieved Documents

---

# Remediation

- Update Guardrails
- Improve Validation
- Expand Detection Rules
